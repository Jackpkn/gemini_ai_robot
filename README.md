# Teleop-Lab

A clean, step-by-step robotics learning workspace (kinematics, MuJoCo, ROS 2, DDS & Zenoh).

## Current Files

- `learning/fk.py` — Forward kinematics practice script (runs directly on Mac with `.venv/bin/python learning/fk.py`).
- `docker/` — Ready-to-use Ubuntu 24.04 + ROS 2 Jazzy (`arm64`) Linux container for when we start building ROS 2 nodes one file at a time.
- `pyproject.toml` — Python 3.12 + `mujoco` + `numpy` + `pytest`.
